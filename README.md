<h1 align="center">🍽️✨ HETUK RESTAURANT WEBSITE ✨🍽️</h1>

<p align="center">
A premium, modern, and fully responsive <b>Restaurant Website</b> built using <b>HTML, CSS, and JavaScript</b>.<br>
This is a <b>Solo Project</b> focused on elegant UI, smooth interactions, and a real-world restaurant experience.
</p>

<hr>

<h2>✨ Features</h2>

• 🎨 Premium Fine-Dining UI Design  
• 📱 Fully Responsive (Desktop / Tablet / Mobile)  
• 🧭 Smooth Navigation with Active Navbar Highlight  
• 🍴 Dynamic Menu Page (API Based)  
• 🥗 Veg / Non-Veg Filter  
• 🍽️ Starter / Main Course / Dessert / Drink Filter  
• 🔄 Combined Filters (e.g. Veg + Starter)  
• 📄 Pagination (Next / Previous)  
• ✨ Custom Animated Loader with Smooth Fade-Out  
• ⏳ Skeleton Loading Effect  
• 🎭 Hover Effects with Blur & Fade Animations  
• ❌ Custom 404 Error Page  
• 👤 Solo Developer Project  

<hr>

<h2>🛠️ Tech Stack</h2>

✨ HTML5  
✨ CSS3 (Flexbox, Grid, Media Queries, Animations)  
✨ JavaScript (ES6, DOM Manipulation)  
✨ REST API (Menu Data Fetching)
